# VIDA Research Group

Premium research compounds for scientific investigation.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- WooCommerce REST API

## Getting Started

1. Install dependencies:
\```bash
npm install
\```

2. Create a `.env` file:
\```env
VITE_WC_URL=http://your-wordpress-site.com
VITE_WC_KEY=ck_your_consumer_key
VITE_WC_SECRET=cs_your_consumer_secret
\```

3. Run the dev server:
\```bash
npm run dev
\```

## Notes
- All products are for Research Use Only (RUO)
- Not for human consumption, diagnostic, or therapeutic use
